# Introduction
<ColorLine :height="4"/>

Vanilla Library is an index site for resources related to vanilla mods. It aims to provide as comprehensive a resource index as possible for developing vanilla mods (that is, data packs + resource packs) for Minecraft: Java Edition.

If you want to get started with vanilla development quickly, see [**Quick Start**](/en/index/quick_start/mod).

## The structure of Vanilla Library

This site has three sections: the documentation site, the monthly magazine *Feature*, and the prerequisite library.

### Documentation site
The documentation site contains a large number of resource indexes related to vanilla mod development. They can be roughly divided into theory and practice. You can enter the documentation from the home page, then click the page you want to browse in the directory on the left according to your needs.
Here is a brief introduction to each section of the library:
- Data pack architecture: an introduction, by category, to the various systems related to data packs, including all commands, other data pack JSON file structures, world generation, and more;
- Resource pack architecture: an introduction to resource-pack systems such as models, textures, and shaders;
- Vanilla mod practice: a large collection of example tutorials that apply the content of the first two sections, with an emphasis on developing vanilla mods under real workloads;
- Reference and friendly links: external links and tool indexes for reference;
- Appendices: series of tutorials scattered throughout the documentation site, collected here for convenient batch access.

### Monthly magazine *Feature*
*Feature* is a platform hosted by the Vanilla Library team for collecting and presenting short articles about vanilla mod development. It facilitates communication among developers and is updated monthly.
*Feature* is an active platform for publishing new content. It is released on the 15th of every month, and readers can enter it from the home page or the *Feature* entry in the upper-right corner.
Anyone is welcome to submit to *Feature*. Any discovery can be submitted, and we welcome everyone to share their findings with developers. See the *Feature* home page for details.

### Vanilla prerequisite library
The prerequisite library contains various prerequisite data packs from China and abroad. Developers can search for and obtain prerequisite packs to support their own projects.
You can enter the prerequisite library through the prerequisite search entry on the home page.

## Getting more from Vanilla Library

Here are some suggestions for using the library and developing vanilla mods.

### Version annotations
Because Minecraft is updated continuously, some tutorials from earlier eras may no longer apply to newer versions. It is therefore important to annotate the versions to which tutorials apply.
This site uses an inline code marker after a tutorial link to indicate the version on which it was based when published. The content may still apply to future versions; developers can verify this themselves.
If an entry has no version marker but its parent list entry does, the entry also applies to the version marked on its parent.
If neither an entry nor any of its parent entries has a version marker, the content is intended to apply to all versions.
Legend:
- `1.13` means the tutorial is based on version 1.13; it may not apply to earlier or later versions and needs to be verified;
- `~1.21` means the tutorial is based on version 1.21, but most of its content applies to earlier versions; it may apply to future versions and needs to be verified;
- `1.20.2~1.20.4` means the tutorial is valid for versions from 1.20.2 through 1.20.4; it may apply to future versions and needs to be verified.

### The right way to “borrow books” from this site
This site contains a large number of links, and most of those links lead to substantial amounts of content. Remember that people have limited energy: reading every article before beginning your own data pack journey is impossible.
We therefore recommend that readers use the site's content selectively and in a sensible order.

- **Opening the library or developing a data pack for the first time?**
  - Go to **[Quick Start](/en/index/quick_start/mod)** for concise advice.
- **A complete beginner**
  - [Recommended Reading for Beginners](/en/index/quick_start/零基础阅读推荐) provides reading suggestions for newcomers starting from zero. Browse it first;
  - after gaining a basic understanding of data pack development, return to this article and read the content that interests you;
- **A data pack author with some experience**
  - Focus on the practice section and use the first two sections as reference;
  - or look for features you are interested in or do not understand well in the earlier sections and read those;
  - if you make a new discovery, submit it to *Feature*!
- **A veteran who has not followed new-version features for a while**
  - Check the wiki's changelog alongside tutorials and other material about new-version features;
  - look for content in this article with version annotations;
  - and, of course, browse *Feature* for the latest and most interesting practices.


If you find an error or omission in this article, or have relevant material to contribute, we welcome your feedback.

### How to use the wiki
Learning and developing vanilla mods inevitably involves the wiki. However, reading the entire wiki is unnecessary. We recommend using the wiki as a dictionary: first read the linked material provided below, then look up unfamiliar information on the wiki when you encounter a passage you do not understand. If you still do not understand it, open the game in the corresponding version and try it out.
Because the wiki retains only the latest version, refer to its history pages when you need information about an older version.
