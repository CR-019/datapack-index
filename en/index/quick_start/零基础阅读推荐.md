# Recommended Reading for Beginners

::: info
This article guides you through learning data packs from the very beginning.
:::

**Wow! It is great that `mcfunction` is going to be your first programming language (just like it is for many people)!**

**The core of a data pack is the function, and functions are made up of commands. Start by reading and experimenting with a command tutorial! Choose whichever of the following introductory tutorials appeals to you:**

- [MC Command Tutorial: Starting “For Real” from Zero - Dahesor](https://www.bilibili.com/read/readlist/rl833427)
- [Introduction to Minecraft Commands and Data Packs - 创小业](https://space.bilibili.com/133430292/lists/8272)
- [Quick Start Series - 大佬萌茶](https://space.bilibili.com/320500029/lists/3167326)
- [See more…](/en/index/参考)

**Need help? Visit [this page](/en/index/水吧#vanilla-mod-development-exchange-off-site-platform) to find a group to join!** Here is a secret: before asking a question, **think about it yourself**. When you ask, **describe in detail** the difficulty you encountered, your game version, and your ideas and attempts so far. This greatly increases the chance that someone can answer you.

**Once you have some command basics (not many are needed!), you can try creating a data pack!**
- [Introduction to Minecraft Commands and Data Packs - 创小业](https://space.bilibili.com/133430292/lists/8272)
- [A Highly Detailed Data Pack Tutorial for Complete Beginners - 大佬萌茶](https://space.bilibili.com/320500029/lists/4238047)
- [Vanilla Technical Development Tutorial - 徐木弦](https://github.com/xu-mu-xian/Minecraft-Vanilla-Techincal-Development-Tutorial)

**After that, try making something of your own! Perhaps an arrow that explodes when shot, or a double jump? Solving real problems hands-on is one of the fastest ways to grow!**

At this point, you will be able to gradually understand most of the content in this library and use it in your own projects.

Of course, the most important thing is to have fun!
