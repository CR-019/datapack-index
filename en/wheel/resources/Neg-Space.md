<InfoCard />

The Negative Space Fontresource pack allows you to add negative space within text in multiple versions, offset the entire following text to the left to allow for variable visual effects, or control the overall length of text fragments.

This resource pack adds a large number of translation keys`{"translate": "space.&lt;space&gt;"}`Just put`&lt;space&gt;`Replace it with any value to directly become the corresponding offset space. For example:`{"translate": "space.-11"}`A space offset by minus 11.

Read its official documentation ([Github](https://github.com/AmberWat/NegativeSpaceFont/blob/master/README.md)) for more information.
