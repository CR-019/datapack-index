<InfoCard />

This library provides a large number of string manipulation methods, such as splicing, case, search, cutting, insertion, etc. Note that this library cannot handle strings with escaped characters.

The usage methods of different functions are written into the corresponding functions.`stringlib:util/...`in the comments. Read its official documentation ([Github](https://github.com/CMDred/StringLib) | [Modrinth](https://modrinth.com/datapack/stringlib)) for details.
