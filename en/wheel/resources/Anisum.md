<InfoCard />

Octagon is a Minecraft module based on NeoForge. It is used to collect items from the loot table and synchronize them to the client creative tag page to facilitate resource integration and content browsing.
 - Configure custom tag page source and sorting through data pack JSON.
 - Support include rules: exact match, wildcard, regular expression.
 - After the server is reloaded, it automatically rescans the loot table and synchronizes it to the player.
 - Supports incremental synchronization of tag page content when a player joins.

Please read its [documentation](https://github.com/Anvil-Dev/Anisum) to learn how to use it. The module jar can be found in [Modrinth](https://modrinth.com/mod/anisum) to download.
