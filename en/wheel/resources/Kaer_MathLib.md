It integrates a large number of achievements in MCcommand and advanced mathematics, and is a library developed in the era of MCfunction macros.

At the beginning, when making the super forging bench, in order to solve the problem of using MCcommand to deduct the player's first N level experience.

My intention in making this library is to provide another reliable library for the development of mcf. It no longer makes developers feel confused when they think that mcf does not have native mathematical operations.

This mathematics library is equipped with the most advanced and powerful numerical calculation system, and has established the industry's top mathematics front-end library in scientific computing for MC data pack. It contains more than 40,000 commands and has an almost complete command interface. It can be said that all the numerical calculation needs you can think of are available here.

Currently it includes 24 major categories: trigonometric function, four integer rules, four array rules, four floating point rules, floating point operations, square root, cube root, ranging, gadgets, geometry, lists, probability, mathematics, exponential function, logarithmic function, factorial-gamma function, linear algebra, scientific computing, scientific computing + particle graphics, special functions, number theory, calculus, Fourier analysis, particle graphics.

Since the birth of the first version in August 2023, this mathematics library has been developed for more than a year and a half. I devoted almost all of my spare time to developing this library. When it was born, it was also called big number arithmetic. v.1.6 version was released on January 1, 2024, and the Chinese name was officially designated as "Kaer's Mathematics Library", but the namespace still uses "large_number".

I just want to do things that others wouldn't do, so that when people step into this area, they won't lament that this is a wilderness. Obviously my efforts have paid off. Doing scientific calculations in MC that everyone used to imagine has now become a reality. If you search for natural logarithms and scientific calculations in the mcfunction language on Github in Chinese, you will find my stuff. I am a pioneer in this area.
