# Featured

::: tip Editor's Note
When sorting out submissions this month, we received two submissions using dialogue systems made in different ways. We thought this was an interesting topic. The dialogue system is a very important component in many map productions, and a beautiful dialogue system can add a lot to the expressiveness of the map. Some authors have made some attempts in the past, such as [Qingluka](https://space.bilibili.com/33229178/)[dialog system] made using shader(https://www.bilibili.com/video/BV1yZ4y1v7Vx/). If your map is still using a chat bar or a book-making dialogue system, you can consider these solutions, which may provide some inspiration for your map creation journey.
